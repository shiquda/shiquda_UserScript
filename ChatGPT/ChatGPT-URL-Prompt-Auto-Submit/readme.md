# ChatGPT URL Prompt Auto Submit

Automatically clicks the submit button when ChatGPT URL contains `?q=` or `?prompt=` parameters.

## Feature

When opening ChatGPT via URL with prefilled query parameters (such as `https://chatgpt.com/?q=your_prompt` or `https://chatgpt.com/?prompt=your_prompt`), ChatGPT fills the composer input but requires you to click send manually. This script monitors the composer submit button and automatically triggers the submit action once the page is ready.
